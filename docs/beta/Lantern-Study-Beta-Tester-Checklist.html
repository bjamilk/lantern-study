Session 1 — First impression & account (30–40 min)

Goal: Landing → signup → onboarding feels clear. Success = can create an account and reach Dashboard without getting stuck.

Landing & cookies

  • 1.1Open home page; skim landing; open Privacy, Terms, Cookies links
  • 1.2Cookie banner → Manage preferences → save; reload — choice sticks
  • 1.3Clear site data; choose Essential only; reload — banner stays dismissed
  • 1.4Clear site data again; choose Accept all; reload — sticks
  • 1.5Re-open Cookie Preference Center from the Cookies page

Sign-up & login

  • 1.6Sign up with email + username; try a taken username — clear error
  • 1.7Complete email verification / OTP; try Resend once
  • 1.8Complete onboarding steps (or Skip) — no stuck screen
  • 1.9Land on Dashboard Getting Started checklist; items make sense
  • 1.10Log out → log in with password
  • 1.11Forgot password → email link → set new password
  • 1.12Optional: Google or Apple sign-in; claim username if prompted

Session 2 — Dashboard, gamification & navigation (20–30 min)

  • 2.1View XP, streak, badges, activity heatmap
  • 2.2Start / complete daily quiz; change study goal mode if available
  • 2.3Open daily quests; refresh if available
  • 2.4Use quick links: AI Tools, Notes, Flashcards, Explore
  • 2.5Toggle theme (sidebar + Settings): light ↔ dark ↔ system — UI stays readable
  • 2.6Toggle Low-Data Mode; note what changes (AI / animations)
  • 2.7Phone: bottom nav Home / Library / Chat / More; open Settings from More
  • 2.8Phone: cookie banner does not block bottom-nav taps
  • 2.9Change / upload avatar from sidebar

Session 3 — Library, notes & flashcards (45–60 min)

Notes

  • 3.1Create a note with title + body
  • 3.2Create a folder; filter / organize notes
  • 3.3Upload a PDF; wait for processing; open preview
  • 3.4Upload PowerPoint (PPT/PPTX) if available; preview / retry if slow
  • 3.5Add a YouTube embed if supported
  • 3.6Voice note → transcription (allow mic)
  • 3.7Generate flashcards from note
  • 3.8Generate quiz / daily quiz from note
  • 3.9Share note with a group (after Session 5 group exists)
  • 3.10Delete a disposable test note

Flashcards

  • 3.11Create a deck + several manual cards
  • 3.12AI-generate cards (Low-Data OFF)
  • 3.13Try modes: Learn · Spaced repetition · Match · Cram · Timed Cram
  • 3.14Grade cards in review; due badge updates
  • 3.15Toggle deck “offline available”
  • 3.16Export deck JSON/CSV
  • 3.17Edit/delete a card; reset SRS on a throwaway deck

Study hub

  • 3.18Open Study hub: review due cards, resume paused session, jump to Library / AI Tools

Session 4 — AI Tools & companion (30–45 min)

Success = AI helps, and failures show a clear message (not a silent “Generate” button).

  • 4.1AI Tools: PDF summarizer → creates note (+ optional flashcards/quiz)
  • 4.2PowerPoint import path works
  • 4.3Paste notes → import & study (try toggles on and off)
  • 4.4Open Lantern AI companion; ask a study question; use a quick prompt
  • 4.5Thumbs up/down on a reply
  • 4.6Notice usage badge / daily limits
  • 4.7Turn Low-Data ON — some AI actions disable with a clear reason
  • 4.8Try weak-topics flashcards if shown
  • 4.9Deliberately use a tiny/empty upload for AI generate — expect a clear error

Session 5 — Groups, chat, questions & tests (60–90 min · 2 users)

Assign Student A (group admin) and Student B (joiner). Highest-priority beta session.

Setup

  • 5.1A: Create a group
  • 5.2B: Open invite link while logged out, then log in — lands back on invite / join
  • 5.3B joins; A opens group info (members, roles)
  • 5.4A: invite by email/phone or approve join request if available
  • 5.5Create a subgroup if available

Chat & questions

  • 5.6Send several group messages
  • 5.7Start a DM between A and B
  • 5.8Submit questions: MCQ, T/F, short answer, fill-in-blank, multi-select
  • 5.9Upvote / downvote; try flag similar/duplicate
  • 5.10Check verified / pending / rejected question states if moderation exists
  • 5.11AI summarize group chat
  • 5.12Generate Questions with AI: paste notes and upload PDF/PPT; questions appear for voting
  • 5.13Long generate: progress or error shown — not a dead button
  • 5.14Light mode: vote buttons on your own questions are readable

Tests, study, duels

  • 5.15Configure a test (types, count, timer); save a preset
  • 5.16Take timed test; pause/resume; flag hard questions
  • 5.17Finish → results → review → analysis from dashboard
  • 5.18Start Study mode / solo practice
  • 5.19A challenges B to a duel; B accepts; both complete; compare results
  • 5.20Decline a challenge; open Challenges inbox
  • 5.21Archive / unarchive group; leave a throwaway group
  • 5.22Admin only: promote/demote or remove member (careful)

Offline from group

  • 5.23From test config: Download for offline
  • 5.24Offline page: rename bundle; start offline test/study
  • 5.25Go online; sync pending results; badge clears

Session 6 — Marketplace (45–60 min · 2 users)

Guest browse

  • 6.1Signed out: browse Marketplace (Academic + Student Life)
  • 6.2Search + category filters
  • 6.3Open listing + seller profile; hit an action that requires sign-in

Seller (User A)

  • 6.4Settings → Marketplace: set country / campus
  • 6.5Create a listing with details (photos if available)
  • 6.6My Listings: edit / deactivate; check stats if shown
  • 6.7Open Inquiries inbox
  • 6.8Open Seller Customers if available

Buyer (User B)

  • 6.9Favorite a listing; save a search
  • 6.10Contact seller (inquiry)
  • 6.11Make an offer → DM: accept / decline / counter
  • 6.12Buy now / campus pickup as far as beta allows
  • 6.13Orders list + order detail (buyer and seller)
  • 6.14Report a disposable listing

Session 7 — Budget (Campus Pocket) (20–30 min)

  • 7.1Set monthly budget / plan
  • 7.2Add expense, income, investment
  • 7.3Create a savings goal
  • 7.4Expense split with another user if available
  • 7.5Push spending toward warning / over-budget banners
  • 7.6Check Insights / tips
  • 7.7Delete a transaction

Session 8 — Settings, privacy & account (25–35 min)

  • 8.1Profile: name, phone, password change
  • 8.2Notification toggles (reminders, marketplace, SRS, digest)
  • 8.3Study defaults: daily goals, shuffle, explanations
  • 8.4Appearance: font size, compact, reduce motion, high contrast
  • 8.5Privacy: visibility, DM policy, online status, study activity
  • 8.6Data & Sync options
  • 8.7Support: FAQ + contact form
  • 8.8Export account JSON (note any rate limit)
  • 8.9Throwaway account only: pause → reactivate (do not delete real accounts unless told)

Session 9 — Cross-cutting quality (do throughout)

Layout & devices

  • 9.1Phone (~390px): no horizontal scroll on Dashboard, Library, Marketplace, Budget, Chat, Login
  • 9.2Desktop (≥1280px): same pages look intentional, not stretched/broken
  • 9.3Modals / AI companion do not cover primary buttons permanently
  • 9.4Mobile chat: list ↔ conversation + Back works

Auth / session edge cases

  • 9.5Session expiry (idle or old tab) → clear toast + clean logout
  • 9.6Deep link (invite or marketplace) while logged out → after login, correct destination
  • 9.7Two tabs: log out in one; other tab behaves safely

Light mode readability

  • 9.8Vote buttons on own question bubbles readable
  • 9.9Dashboard heatmap / charts readable
  • 9.10Marketplace cards + seller header readable
  • 9.11Login placeholders and buttons readable

End-of-session feedback (fill after each major session)

  1. What were you trying to do?
  1. Did you succeed? (Y / N) — where did you pause or get confused?
  1. Bug? Steps to reproduce + screenshot filename
  1. Would you use this weekly? (1 = no · 5 = yes)
  1. Missing feature that blocked a task?
