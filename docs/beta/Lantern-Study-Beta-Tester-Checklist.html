Session 1 — First impression & account (30–40 min)

Goal: Landing → signup → onboarding feels clear. Success = can create an account and reach Dashboard without getting stuck.

Landing & cookies

  • 1.1Open home page; skim landing; open Privacy, Terms, Cookies links
  • 1.2Cookie banner → Manage preferences → save; reload — choice sticks
  • 1.3Clear site data; choose Essential only; reload — banner stays dismissed
  • 1.4Clear site data again; choose Accept all; reload — sticks
  • 1.5Re-open Cookie Preference Center from the Cookies page

Sign-up & login

  • 1.6Sign up with email + username; try a taken username — clear error
  • 1.7Complete email verification / OTP; try Resend once (cooldown behaves)
  • 1.8Complete onboarding steps (or Skip) — no stuck screen
  • 1.9Land on Dashboard Getting Started checklist; items make sense
  • 1.10Log out → log in with password
  • 1.11Forgot password → email link → set new password → log in with new password
  • 1.12Optional: Google or Apple sign-in; claim username if prompted
  • 1.13Optional: idle / expired session → clear toast + clean re-login

Session 2 — Dashboard, gamification & navigation (20–30 min)

  • 2.1View XP, streak, badges, activity heatmap
  • 2.2Start / complete daily quiz; change study goal mode if available
  • 2.3Open daily quests; refresh if available
  • 2.4Use quick links: AI Tools, Notes, Flashcards, Explore/Market, Study, Offline, Budget
  • 2.5Toggle theme (sidebar + Settings): light ↔ dark ↔ system — UI stays readable
  • 2.6Toggle Low-Data Mode; note what changes (AI / animations)
  • 2.7Phone: bottom nav Home / Library / Chat / More; open Settings from More
  • 2.8Phone: cookie banner does not block bottom-nav taps
  • 2.9Change / upload avatar from sidebar or profile
  • 2.10Later: resume a paused test or study session from Dashboard if one exists

Session 3 — Library, notes & flashcards (60–75 min)

Notes — create, organize, pin & archive

  • 3.1Create a typed note (title + body); confirm autosave
  • 3.2Search notes; use Mine vs Shared filter if shown
  • 3.3Create a folder; move / filter notes by folder
  • 3.4Rename folder via folder ⋯ menu (web and phone)
  • 3.5Delete folder — notes remain under All notes (not deleted)
  • 3.6Phone: folder ⋯ opens Rename / Delete (menu not clipped / cut off)
  • 3.7Pin / unpin a note; pinned notes sort to top of Active
  • 3.8Archive / unarchive a note; Active vs Archived filter works

Notes — imports & AI

  • 3.9Upload a PDF; wait for processing; open preview
  • 3.10Upload PowerPoint (PPT/PPTX); preview or clear retry / error if slow
  • 3.11YouTube import → linked video opens
  • 3.12Photos import (multi) → gallery works
  • 3.13Voice note → transcription (≥2s, allow mic); transcript appears
  • 3.14Bad / tiny upload shows clear error (not silent fail)
  • 3.15Generate flashcards from note
  • 3.16Generate / regenerate quiz from note
  • 3.17Summarize / Smart Notes with enough content

Notes — share & collaborate

  • 3.18Share note with a group (after Session 5 group exists)
  • 3.19Collaborators: invite viewer/editor; change role; remove
  • 3.20Share link: create → copy → open while logged out then in → revoke
  • 3.21Comments: post + refresh
  • 3.22Non-owner: Make a copy of a shared note
  • 3.23Hard-delete a disposable note

Flashcards

  • 3.24Create a deck + several manual cards
  • 3.25Create cloze card; image occlusion card (if available)
  • 3.26AI-generate cards (Low-Data OFF)
  • 3.27Try modes: Learn · Spaced repetition · Match · Cram · Timed Cram
  • 3.28Grade cards in review; due badge updates
  • 3.29Toggle deck “offline available”
  • 3.30Export deck JSON/CSV
  • 3.31Edit/delete a card; reset SRS on a throwaway deck
  • 3.32Deck collaborators if available

Study hub

  • 3.33Open Study hub: review due cards, resume paused session, jump to Library / AI Tools

Session 4 — AI Tools & companion (30–45 min)

Success = AI helps, and failures show a clear message (not a silent “Generate” button).

  • 4.1AI Tools: PDF summarizer → creates note (+ optional flashcards/quiz)
  • 4.2PowerPoint import path works
  • 4.3Paste notes → Import & study (try toggles on and off)
  • 4.4Open Lantern AI companion; ask a study question; use a quick prompt
  • 4.5Thumbs up/down on a reply
  • 4.6Notice usage badge / daily limits
  • 4.7Turn Low-Data ON — some AI actions disable with a clear reason
  • 4.8Try weak-topics flashcards if shown
  • 4.9Deliberately use a tiny/empty upload for AI generate — expect a clear error

Session 5 — Groups, chat, questions & tests (60–90 min · 2 users)

Assign Student A (group admin) and Student B (joiner). Highest-priority beta session.

Setup

  • 5.1A: Create a group (name / avatar)
  • 5.2B: Open invite link while logged out, then log in — lands back on invite / join
  • 5.3B joins; A opens Group Info (members, roles)
  • 5.4A: invite by email/phone or approve join request if available
  • 5.5Create a subgroup if available

Chat & DMs

  • 5.6Send, edit, delete group messages; reply; typing indicator
  • 5.7Start a DM between A and B
  • 5.8Mute group notifications (pick a duration) → unmute
  • 5.9Mute / unmute DM; archive / unarchive DM; delete a disposable DM
  • 5.10Group ⋮ overflow menu scrolls; all actions reachable on phone

Questions

  • 5.11Use question visibility filters
  • 5.12Submit questions: MCQ, multi-select, T/F, fill-in-blank, matching, diagram (as available)
  • 5.13Upvote / downvote; try flag similar/duplicate
  • 5.14Check verified / pending / rejected question states if moderation exists
  • 5.15AI summarize group chat
  • 5.16Generate Questions with AI: paste notes and upload PDF/PPT; questions appear for voting
  • 5.17Long generate: progress or error shown — not a dead button
  • 5.18Light mode: vote buttons on your own questions are readable

Tests, study, duels

  • 5.19Configure a test (types, count, timer); save a preset
  • 5.20Take timed test; pause/resume; flag hard questions
  • 5.21Finish → results → review incorrect → analysis from dashboard
  • 5.22Start Study mode / solo practice
  • 5.23A challenges B to a duel; B accepts; both complete; compare results
  • 5.24Decline a challenge; open Challenges inbox

Leave, archive & roles

  • 5.25Leave group as a non-sole admin (Danger Zone)
  • 5.26Sole admin cannot leave until promoting another admin
  • 5.27Archive / unarchive group
  • 5.28Admin only: promote / demote or remove member (careful)

Offline from group

  • 5.29From test config: Download for offline
  • 5.30Offline page: rename bundle; start offline test/study
  • 5.31Go online; sync pending results; badge clears
  • 5.32Delete a disposable offline bundle

Session 6 — Marketplace (45–60 min · 2 users)

Guest browse

  • 6.1Signed out: browse Marketplace (Academic + Student Life)
  • 6.2Search + category filters
  • 6.3Open listing + seller profile; hit an action that requires sign-in

Seller (User A)

  • 6.4Settings → Marketplace: set country / campus
  • 6.5Complete seller onboarding if shown
  • 6.6Create a listing with details (photos if available)
  • 6.7My Listings: edit / deactivate; check stats if shown
  • 6.8Coupons / campaigns / bundles if exposed
  • 6.9Open Inquiries inbox
  • 6.10Open Seller Customers / insights if available

Buyer (User B)

  • 6.11Favorite a listing; save a search
  • 6.12Contact seller (inquiry)
  • 6.13Make an offer → DM: accept / decline / counter
  • 6.14Buy now / campus pickup as far as beta allows
  • 6.15Orders list + order detail (buyer and seller)
  • 6.16Seller marks ready for pickup → complete flow (if available)
  • 6.17Report a disposable listing

Session 6b — Jobs board (45–60 min · solo or paired)

Pair Candidate + Employer accounts when possible. Success = search → apply → employer moves status without dead ends.

Candidate

  • 6b.1Jobs home: search + filters (type, remote, pay, sort)
  • 6b.2Save a search; manage saved searches
  • 6b.3Save / unsave a job; open job detail
  • 6b.4Trust badge / scam soft-flags are readable
  • 6b.5Apply in-app and/or external apply tracking
  • 6b.6Report a job with a structured reason
  • 6b.7Open company profile from a job
  • 6b.8My Applications list updates after apply
  • 6b.9Interview / offer visibility if scheduled
  • 6b.10Deadline / calendar export if shown

Employer (paired or second account)

  • 6b.11Create / edit a job posting
  • 6b.12Company profile: logo, about; invite recruiter if available
  • 6b.13Applicants pipeline: move candidate status
  • 6b.14Bulk status move + CSV export if available
  • 6b.15Message templates
  • 6b.16Schedule an interview
  • 6b.17Offer / hire close-out
  • 6b.18Hiring analytics / posting insights
  • 6b.19Deadline reminders if shown

Session 7 — Budget (20–30 min)

  • 7.1Set monthly budget / plan
  • 7.2Add expense, income, investment
  • 7.3Create a savings goal / wallet
  • 7.4Expense split with another user if available
  • 7.5Push spending toward warning / over-budget banners
  • 7.6Check Insights / tips
  • 7.7Delete a disposable transaction

Session 8 — Settings, privacy & account (20–30 min)

  • 8.1Profile: name, phone, password change; avatar
  • 8.2Notification toggles (push/email/digest/reminders/group/marketplace/SRS)
  • 8.3Study defaults: daily goals, SRS new cards, shuffle, explanations
  • 8.4Appearance: font size, compact, animations, reduce motion, high contrast
  • 8.5Privacy: profile visibility, DM policy, discoverability
  • 8.6Marketplace campus preference
  • 8.7Data & Sync options
  • 8.8Support: FAQ + contact form
  • 8.9Export account JSON (note any rate limit)
  • 8.10Optional: import into another account
  • 8.11Throwaway account only: pause → sign in → reactivate
  • 8.12Throwaway only: permanent delete after export (do not delete real accounts unless told)

Session 9 — Cross-cutting quality (30–45 min · also do throughout)

Layout & devices

  • 9.1Phone (~390px): no horizontal scroll on Dashboard, Library, Notes, Chat, Market, Jobs, Budget, Login
  • 9.2Desktop (≥1280px): sidebar + content look intentional, not stretched/broken
  • 9.3Modals / AI companion do not cover primary buttons permanently
  • 9.4Mobile chat: list ↔ conversation + Back works

Empty, error & loading

  • 9.5Empty states: no notes / decks / groups / listings / jobs / offline bundles
  • 9.6Error toasts for failed AI / upload / network
  • 9.7Loading states do not freeze forever

Auth / session edge cases

  • 9.8Session expiry (idle or old tab) → clear toast + clean logout
  • 9.9Deep link (invite / note share / marketplace / jobs) while logged out → after login, correct destination
  • 9.10Two tabs: log out in one; other tab behaves safely

Light + dark readability

  • 9.11Vote buttons on own question bubbles readable
  • 9.12Dashboard heatmap / charts readable
  • 9.13Marketplace cards + seller header readable
  • 9.14Jobs cards + filters readable
  • 9.15Login placeholders and buttons readable
  • 9.16Retest any earlier bugs in both themes

End-of-session feedback (fill after each major session)

  1. What were you trying to do?
  1. Did you succeed? (Y / N) — where did you pause or get confused?
  1. Bug? Steps to reproduce + screenshot filename
  1. Would you use this weekly? (1 = no · 5 = yes)
  1. Missing feature that blocked a task?
